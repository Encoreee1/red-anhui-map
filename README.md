# 红色安徽 — 交互式党史学习数字地图

> 信息技术融合组参赛作品 · "数智里的中国" · 2026

## 📖 简介

一款集**数字地图**、**历史时间轴**、**数据可视化**和**知识问答**于一体的单页面 H5 交互应用，聚焦安徽省 16 个地级市的红色文化资源，通过数字技术让用户沉浸式学习党史知识。

**支持完全离线运行**，解压即用，无需网络。

## 🎯 五大板块

| 板块 | 功能 |
|------|------|
| 🏠 **封面动画** | Canvas 粒子系统，红金双色粒子浮动 + 连线，渐变金属质感标题 |
| 🗺️ **数字地图** | 安徽行政区划地图，17 处红色地标散点，4 类筛选，点击查看详情卡片 |
| 📅 **历史时间轴** | 1921—1949 年 12 个关键节点，拖拽/触摸滑动，点击展开完整描述 |
| 📊 **数据看板** | 柱状图（各地市分布）+ 饼图（类型占比）+ 数字滚动统计动画 |
| ❓ **知识问答** | 20 题题库随机 10 题，30 秒倒计时，即时对错反馈，分级结果评语 |

## 🚀 使用方法

```
解压 → 双击 index.html
```
